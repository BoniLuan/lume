# Security policy

Lume stores personal financial data. Please do not open a public issue for a
suspected vulnerability or include real credentials, session tokens, transaction
details, or database dumps in any report.

Until a private security contact is published, use GitHub's private vulnerability
reporting feature for this repository. Include the affected version, reproducible
steps using synthetic data, impact, and any suggested mitigation.

The `main` branch is the only supported line during initial development. Security
fixes will be documented in release notes once tagged releases begin.
